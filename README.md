# ChatSystem 最小可运行骨架

这是一个基于 Python 标准库的最小即时聊天系统骨架，使用 `socket`、`threading`、`json` 实现。

## 目录结构

```text
server/server.py      # TCP 聊天服务器
client/client.py      # 命令行聊天客户端
common/protocol.py    # JSON Lines 协议收发函数
README.md             # 运行说明
```

## 通信协议

项目使用 JSON Lines 格式：

- 每条消息是一个 JSON 对象
- 每条消息以换行符 `\n` 结尾
- 示例：

```json
{"type": "message", "content": "hello"}
```

心跳消息也继续使用 JSON Lines。客户端登录成功后会启动 heartbeat 线程，每 10 秒发送：

```json
{"type": "heartbeat"}
```

服务器登录成功时记录该用户最近心跳时间，收到 heartbeat 时刷新时间，并由后台监控线程每 5 秒检查一次。若某个在线用户超过 30 秒没有心跳，服务器会关闭该连接、从在线列表移除该用户，并向其他在线用户广播“<用户名> 已离线”。

## 运行方法

先在项目根目录运行服务器：

```bash
python server/server.py
```

再打开一个或多个新终端，在项目根目录运行客户端：

```bash
python client/client.py
```

客户端输入普通文本后按回车即可发送消息。服务器会把消息广播给所有在线客户端。

客户端连接后需要先输入用户名。用户名必须唯一，如果用户名已在线，客户端会提示重新输入。

查看在线用户：

```text
/online
```

发送一对一私聊：

```text
/msg <用户名> <消息内容>
```

例如：

```text
/msg Bob hello
```

私聊只会发送给目标用户，其他在线用户不会收到。当前实现允许给自己发送私聊。

创建群组：

```text
/create_group <群名>
```

加入群组：

```text
/join_group <群名>
```

退出群组：

```text
/leave_group <群名>
```

发送群聊消息：

```text
/gmsg <群名> <消息内容>
```

例如：

```text
/create_group study
/join_group study
/gmsg study hello
```

群聊消息只会发送给该群组内的在线成员。当前实现中，用户退出登录时会自动从所有群组移除。

查看最近 20 条相关历史消息：

```text
/history
```

历史消息存储在 SQLite 中。私聊历史包含当前用户发送或接收的私聊；群聊历史包含当前用户当前所在群组的群消息。群组成员关系目前保存在内存中，服务器重启后需要重新创建/加入群组，之后仍可查询 SQLite 中已有的对应群消息。

退出客户端：

```text
/quit
```

心跳机制测试建议：

```text
1. 启动服务器：python server/server.py
2. 启动两个客户端，分别登录 Alice 和 Bob。
3. Bob 输入 /quit，Alice 应收到 Bob 已离线的系统消息。
4. 再次登录 Bob 后输入 /stop_heartbeat，Bob 客户端不会退出，socket 也不会主动关闭。
5. 服务器约 30 秒后应判定 Bob 离线。
6. 也可以直接关闭 Bob 客户端窗口，验证异常断开清理。
7. Alice 输入 /online，列表中不应再包含 Bob，服务器应保持运行。
```

`/stop_heartbeat` 是仅用于测试的客户端命令，用来停止当前客户端继续发送 heartbeat，不会关闭 socket，也不会退出程序。

停止服务器：

```text
Ctrl+C
```

## 当前已实现

- 服务器监听 `127.0.0.1:9000`
- 每个客户端连接后由独立线程处理
- 服务器维护在线客户端列表
- 客户端使用唯一用户名登录
- 客户端发送聊天消息后，服务器广播给所有客户端
- 客户端可用 `/msg <用户名> <消息内容>` 发送一对一私聊
- 客户端可用 `/create_group`、`/join_group`、`/leave_group`、`/gmsg` 使用群聊
- 客户端可用 `/history` 查看最近 20 条相关历史消息
- 客户端可用 `/online` 查看在线用户
- 客户端启动接收线程，持续打印服务器消息
- 客户端输入 `/quit` 后退出
- 客户端异常断开时，服务器不会崩溃

## 压力测试

项目提供了一个 50 客户端并发连接压力测试脚本，用于验证服务器在多客户端同时登录、发送普通聊天消息、请求在线列表、保持连接并正常退出时的稳定性。

先在项目根目录启动服务器：

```bash
python server/server.py
```

再打开另一个终端，在项目根目录运行：

```bash
python tests/stress_test.py
```

脚本会模拟 `user_001` 到 `user_050` 共 50 个客户端，并输出成功连接客户端数量、登录成功数量、消息发送成功数量、失败数量和总耗时。验收时确认输出中大部分或全部客户端连接成功，并观察服务器进程保持运行、不崩溃。
